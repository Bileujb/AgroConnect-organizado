# Modelos de domínio (exercícios)

Classes JavaScript criadas nos exercícios da disciplina para representar o domínio do AgroConnect
(Usuário, Produtor, Consumidor, Produto, Pedido, ItemPedido, Avaliação, Notificação e SensorIoT).

**Elas não são usadas pelo aplicativo.** O app trabalha direto com os dados (JSON) que vêm da API
Java. Por isso ficam aqui, na documentação, e não em `frontend/src/`.
