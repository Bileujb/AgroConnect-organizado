# Models dos exercícios

Classes de domínio (Usuario, Produtor, Consumidor, Produto, Pedido, ItemPedido, Avaliacao, Notificacao, SensorIoT) criadas nos exercícios da faculdade, antes da integração com a API Java.

Elas ficam aqui como registro do trabalho acadêmico e **não fazem parte do aplicativo**: as telas trabalham com os objetos JSON devolvidos pela API. Por estarem fora de `src/`, não entram no bundle do Expo.
